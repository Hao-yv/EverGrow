# EverGrow 数据库设计

> 基于 MySQL + PyMySQL，满足合格交互平台的常用需求：知识库、用户、多轮问答

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| **适度精简** | 保留核心交互能力 |
| **职责分离** | 向量内容存 Chroma，MySQL 存元数据与业务数据 |
| **匿名友好** | 支持未登录使用（session_id），登录后关联 user_id |
| **字符集** | 统一 `utf8mb4` |

---

## 二、表结构概览

| 表 | 用途 |
|------|------|
| **knowledge_articles** | 知识元数据（与 Chroma 对应） |
| **users** | 用户 |
| **conversations** | 问答会话（支持匿名/登录） |
| **conversation_messages** | 会话消息（含引用文档 ID） |

共 **4 张表**。

---

## 三、表结构详情

### 3.1 knowledge_articles（知识元数据）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| chroma_doc_id | VARCHAR(64) UNIQUE | Chroma 文档 ID |
| title | VARCHAR(200) | 问题/标题 |
| stage | VARCHAR(30) | 年龄段（幼儿期/学龄前/小学/初中/高中/通用） |
| category | VARCHAR(30) | 矛盾类型（行为习惯/情绪管理/…） |
| source_file | VARCHAR(255) | 原始文件名 |
| source_author | VARCHAR(100) | 作者/机构 |
| created_at | DATETIME | 创建时间 |

索引：`uk_chroma_doc_id`、`idx_stage_category`

---

### 3.2 users（用户）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| username | VARCHAR(50) UNIQUE | 用户名 |
| password_hash | VARCHAR(255) | 密码哈希 |
| nickname | VARCHAR(50) | 昵称 |
| is_active | TINYINT(1) DEFAULT 1 | 是否启用 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

初始管理员：username=admin, password=admin（由 `scripts/init_db.py` 创建）

---

### 3.3 conversations（会话）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| user_id | BIGINT FK NULL | 用户（匿名为空） |
| session_id | VARCHAR(64) | 匿名会话标识 |
| title | VARCHAR(100) | 会话摘要（首问截断） |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

- 登录用户：user_id 有值，session_id 可空  
- 匿名用户：user_id 为空，session_id 必填（如 cookie/uuid）

---

### 3.4 conversation_messages（消息）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| conversation_id | BIGINT FK | 所属会话 |
| role | ENUM('user','assistant') | 角色 |
| content | TEXT | 消息内容 |
| retrieved_doc_ids | JSON | 引用的 chroma_doc_id 列表 |
| created_at | DATETIME | 创建时间 |

---

## 四、ER 关系

```
knowledge_articles

users ─── conversations ─── conversation_messages
  │              │
  └──────────────┘  (user_id 可空，匿名用 session_id)
```

---

## 五、初始化

```bash
# 推荐：Python 脚本（含 admin 用户）
pip install pymysql pyyaml bcrypt
python scripts/init_db.py

# 或：直接执行 SQL
mysql -u root -p evergrow_db < sql/init_schema.sql
```
