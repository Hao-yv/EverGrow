# EverGrow 答辩 PPT 生成提示词

> 将下方整段提示词复制给 AI（如 ChatGPT、Claude、Cursor），可生成符合评分要点的答辩 PPT 大纲与每页要点。

---

## 提示词（复制使用）

```
请为我制作一份项目答辩 PPT 的大纲与每页内容要点，项目为「亲子矛盾 RAG 智能问答平台 EverGrow」。

【答辩要求】
- 总时长：5–7 分钟
- PPT 页数：10–12 页（含封面、目录、致谢）
- 需满足以下评分要点（总分 100）：

1. 内容陈述（20 分）：思路清晰、重点突出；准确阐述项目背景、研究意义、社会需求；说明研究在经济社会发展、可持续发展中的价值；概述国内外相关研究现状与发展趋势；清晰说明技术路线、系统方案或算法思路。

2. 问题理解与解决过程（40 分）：深入理解项目任务与需求，明确研究问题与目标；充分的问题分析、合理的技术路线、可行的系统架构或算法设计；说明关键技术问题、解决方案及决策依据；体现大数据工程方法/技术/工具的应用；考虑社会、环境、安全等因素。

3. 回答问题情况（30 分，答辩现场）：PPT 需为现场问答提供支撑，便于说明文献综述过程、技术选型依据、研究方案可行性。

4. PPT 与表达（10 分）：结构合理、内容规范；图表清晰、有效展示数据或系统设计；表述流畅、逻辑连贯、时间分配合理。

【项目核心信息】
- 项目名称：EverGrow - 亲子矛盾 RAG 智能问答平台
- 定位：面向 0–18 岁各成长阶段，为家长提供可检索、可溯源、可操作的亲子矛盾解决方案
- 技术路线：RAG（检索增强生成）— 向量检索 + LLM 生成，答案基于专业语料库
- 语料：208 篇 docx/doc，来自专家/学校分享，涵盖幼儿期至青春期
- 矛盾类型：行为习惯、情绪管理、社交发展、学习态度、亲子沟通、生活自理等
- 技术栈：Chroma 向量库、云物 LLM API、text-embedding-ada-002、MySQL、LangChain、FastAPI
- 系统流程：用户提问 → 向量检索（可选年龄段过滤）→ 重排序 → LLM 生成（含引用来源）→ 输出回答 + 引用 + 相关推荐
- 社会价值：缓解家长育儿焦虑、促进亲子关系、补充家庭教育资源
- 可持续发展：可扩展语料、迭代模型、服务更多家庭

【输出格式】
请按以下结构输出，每页给出：页码、标题、3–5 条要点（可直接用于 PPT 文案）、建议配图类型（如有）。

1. 封面
2. 目录
3. 项目背景与意义
4. 社会需求与研究价值
5. 国内外研究现状与趋势
6. 研究问题与目标
7. 技术路线与系统架构（含流程图描述）
8. 关键技术：RAG 与向量检索
9. 语料与知识库构建
10. 系统实现与演示要点
11. 社会、环境与安全考量
12. 总结与展望 / 致谢
```

---

## 使用建议

1. **复制整段**：从「请为我制作」到「总结与展望 / 致谢」全部复制到 AI 对话。
2. **根据输出细化**：AI 生成的是大纲与要点，可再让其逐页展开或生成具体文案。
3. **补充图表**：请 AI 用 Mermaid 或文字描述流程图，再在 PowerPoint / Keynote 中绘制。
4. **控制时长**：5–7 分钟约对应 10–12 页，每页 30–50 秒，重点放在「问题理解与解决过程」（40 分）和「内容陈述」（20 分）。
